Status

Software stack: verified in simulation (82 firmware host tests, 61 Go, 68 gateway, 12 end-to-end). Hardware: nothing has run on a board yet.

Port built for every milestone (one branch each): MSPM0 bootloader 18.1 KB of 28 KB and apps about 29 KB of 48.6 KB (measured links); full end-to-end suite passes on the MSPM0 flash map in simulation. Headless flashing and every pin, clock and timing number still need a board: see docs/mspm0-bench-steps.md.

Port milestones

Each milestone has a git branch with the code as it was when that milestone was finished; main has all of them.

Concept model, not to scale. Pin and board facts come from TI documents as noted in docs/mspm0-port-plan.md; anything else is an estimate until measured on the bench. Nothing writes to the Sentra: standard OBD-II requests only.
